About LavenderMC ♡

LavenderMC is a personal, non-commercial project built to make hosting modded Minecraft servers less confusing, especially for beginners. The dashboard runs locally rather than as a public server-hosting service.

The project aims to support searching Minecraft modpacks, viewing versions and compatibility, and downloading permitted server files through supported mod platforms. Features and integrations are still in development.
